# Manual Testing Checklist

Run the app in a current version of Chrome, Edge, Firefox, or Safari.

- [ ] `index.html` loads without missing CSS or JavaScript files.
- [ ] The clock and date update automatically.
- [ ] A future target date displays a T-minus countdown.
- [ ] A past target date displays a T-plus elapsed count.
- [ ] Editing the goal title updates the preview.
- [ ] Adding and removing milestones updates the editor and preview.
- [ ] Completing and uncompleting a milestone updates the completion count and progress.
- [ ] Each of the four themes applies correctly.
- [ ] Uploading a supported image updates the preview.
- [ ] Removing the background image restores the default appearance.
- [ ] Reloading the page restores saved settings in the same browser.
- [ ] Downloading the wallpaper creates a 1080 × 1920 PNG.
- [ ] The editor remains usable on a narrow mobile viewport.

## Notes

This is a manual checklist, not a claim that every browser/device combination has been tested. The application does not require a backend or package installation.
